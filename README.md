# Soorena Portfolio

A personal portfolio website built to showcase my projects, skills, and experience as a developer.

The website focuses on a clean, responsive, and modern interface while keeping the project structure simple and maintainable.

## 🌐 Live Demo

👉 [View Live Portfolio](<https://soorenadev.ir>)

## ✨ Features

- Responsive portfolio design
- Dynamic project rendering with JavaScript
- Reusable `Project` class for project data
- Project cards with:
  - Project title
  - Description
  - Preview image
  - Live demo link
  - Source code link
- Bootstrap responsive layout
- Bootstrap Icons
- Poppins typography
- Interactive hover effects
- Mobile-friendly design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap
- Bootstrap Icons
- Google Fonts - Poppins
